# Astra Mobile

وكيل ذكي للهاتف Android. الهدف هو بناء Agent يستطيع فهم هدف المستخدم، التخطيط، رؤية الشاشة، تنفيذ الإجراءات، التحقق من النتائج، والتعافي من الأخطاء مع نظام موافقات للعمليات الحساسة.

## الإصدار الحالي

**v0.1.0 — الأساس**

يتضمن:
- واجهة عربية أولية.
- نواة Agent: Parser/Planner/Executor/Verifier/Recovery كمراحل معمارية.
- خدمة Android Accessibility لاستقبال محتوى الواجهة وتنفيذ النقر والإيماءات والكتابة.
- زر لتفعيل خدمة التحكم من إعدادات Android.
- GitHub Actions لبناء APK Debug تلقائيًا.

## الخطة

1. حلقة Observe → Plan → Act → Verify → Recover.
2. فهم Screenshot + Accessibility Tree.
3. أدوات Tap/Swipe/Type/Back/Open App.
4. Browser Agent.
5. الملفات وTermux.
6. الذاكرة والسجل.
7. الصوت.
8. Skills وMulti-Agent.
9. نظام صلاحيات وموافقات متقدم.

## الأمان

العمليات الحساسة مثل الإرسال والحذف والشراء والتحويلات يجب أن تمر عبر طبقة موافقة صريحة. لا يهدف المشروع إلى تجاوز حماية Android أو صلاحيات التطبيقات.
